# Amazon-E-Commerce-Sales-Analysis

## Project Overview
This project analyzes sales performance in different products to identify trends, high performing products. The dashboard helps business stakeholders make data driven decisions to increase revenue.

## Dataset
Sample E commerce dataset.
Key column: Category, Product Name, Actual Price, Discounted Price, Product ID, Review, Rating.

## Tools Used 
- Power BI

## Analysis Process 
- Data cleaning and formatting
- Charts and visual analysis

## Key Insights
- Top 5 actual price by category
- Top 10 review by category
- Rating by actual and discounted price
- Top 5 discounted price by product
